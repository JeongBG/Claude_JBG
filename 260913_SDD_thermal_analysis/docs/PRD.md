# PRD: Wafer 열화상 온도 분석 대시보드

## 1. 개요

### 프로젝트 목적
열화상 카메라로 촬영한 hot-plate 단독 이미지 4장과 wafer 안착 상태 이미지 4장(1~4사분면)을 한 화면에서 확인하고, 온도 수치 데이터를 근거로 wafer 표면 온도 분포를 정량적으로 파악할 수 있는 웹 대시보드를 만든다.

### 타겟 사용자
반도체 공정 장비를 다루는 엔지니어 본인. 혼자서 측정 데이터를 빠르게 확인하고 분석하는 용도로 사용하며, 별도의 팀 공유나 설명 자료 제작은 고려하지 않는다.

### 핵심 가치 제안
원본 열화상 이미지(raw)와 온도 수치 기반 분석 결과를 한 화면에서 함께 제공하여, "촬영 원본을 눈으로 확인"하는 것과 "수치로 균일도·이상 유무를 판단"하는 것을 동시에 할 수 있게 한다.

---

## 2. 기능 요구사항

### 기능 1: 열화상 원본 이미지 대시보드

**사용자 스토리**
> 엔지니어로서, hot-plate 4장(top/bottom/left/right)과 wafer 4장(1~4사분면) 원본 열화상 이미지를 한 화면에서 정리된 형태로 보고 싶다, 촬영이 제대로 되었는지와 전반적인 온도 패턴을 빠르게 훑어보기 위해.

**수용 기준**
- [ ] hot-plate 4장과 wafer 4장이 각각 별도 그룹(섹션)으로 구분되어 표시된다.
- [ ] 각 이미지에는 어떤 위치(top/bottom/left/right, 1~4사분면)를 촬영한 것인지 라벨이 함께 표시된다.
- [ ] 임의의 이미지 1장을 선택하면 원본 화질 그대로 확대해서 볼 수 있다.

### 기능 2: Wafer 온도 분포 정량 분석

**사용자 스토리**
> 엔지니어로서, wafer 4개 사분면의 온도 수치 데이터를 기반으로 최고/최저/평균 온도와 균일도, hot spot·cold spot 위치를 확인하고 싶다, wafer 표면 온도가 공정 기준에 맞게 균일한지 판단하기 위해.

**수용 기준**
- [ ] wafer 4개 사분면 각각에 대해 최고/최저/평균 온도 수치가 화면에 표시된다.
- [ ] wafer 전체 기준 온도 균일도(최대-최소 편차 등 수치화된 지표)가 화면에 표시된다.
- [ ] 온도가 가장 높은 지점과 가장 낮은 지점이 이미지 상에 시각적으로 표시된다.
- [ ] 4개 사분면 중 일부 데이터가 비어있거나 형식이 맞지 않을 경우, 해당 사분면은 "분석 불가"로 표시되고 나머지 사분면 분석은 정상적으로 표시된다.

### 기능 3: Hot-plate ↔ Wafer 비교 분석

**사용자 스토리**
> 엔지니어로서, hot-plate 단독 온도와 wafer를 올렸을 때의 온도를 같은 위치 기준으로 비교하고 싶다, wafer로 인한 온도 편차(열전달 특성)를 파악하기 위해.

**수용 기준**
- [ ] hot-plate 단독 온도와 wafer 안착 시 온도가 같은 화면에서 나란히 비교된다.
- [ ] 같은 위치 기준 온도 차이(편차)가 수치 또는 시각적 표시(색상 등)로 나타난다.
- [ ] hot-plate와 wafer 이미지의 위치 기준이 서로 다르거나 대응이 불확실한 경우, 사용자가 이를 인지할 수 있도록 안내 문구가 표시된다.

---

## 3. 비기능 요구사항

### 성능
- 대시보드 최초 진입 시 8장의 이미지와 분석 결과가 5초 이내에 모두 표시된다.

### 보안
- 외부 사용자 접근이나 로그인 기능은 필요하지 않다 (본인 단독 사용 전제).

### 접근성
- 데스크톱 화면(1920x1080 기준)에서 이미지와 수치가 잘리지 않고 모두 확인 가능해야 한다.

---

## 4. 제약사항

### 기술적 제약
- 이번 프로젝트에서 사용할 데이터셋(이미지 8장 + 온도 수치 데이터)은 고정된 1세트이며, 새로운 세트 업로드 기능은 이번 범위에 포함하지 않는다.

### 비즈니스 제약
- 별도 일정/예산 제약 없음.

---

## 5. 성공 지표
- hot-plate 4장, wafer 4장 원본 이미지를 대시보드 진입 즉시 모두 확인할 수 있다.
- wafer 온도 균일도 수치와 hot/cold spot을 이미지 없이 숫자만으로도 판단할 수 있는 수준으로 정리되어 표시된다.
- hot-plate와 wafer 온도를 비교한 결과를 통해 "wafer로 인한 온도 편차가 있는지 없는지"를 한 문장으로 결론지을 수 있다.
